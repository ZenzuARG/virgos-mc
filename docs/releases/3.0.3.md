# Virgos-MC 3.0.3

## Distant Horizons

- Server-authoritative handshake and shared LOD synchronization are enabled.
- Aggressive low-player transfer profile: server sync/generation 200, client sync 200 and generation 100.
- QA measured 863 FullData rows per minute during a live 60-second transfer window.
- The client cache is persisted in `Distant_Horizons_server_data`; reconnects reuse the downloaded LOD.

## Client memory

The installer now offers 8, 10 or 12 GiB, with 8 GiB as the minimum. Legacy 4/5/6 GiB preferences migrate to 8 GiB.
