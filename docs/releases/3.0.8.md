# Virgos-MC 3.0.8 — server-side claim entry

The existing **P** shortcut now offers **Reclamar parcela** on free land and opens the permissions menu after a confirmed personal claim. Existing owned claims open their permissions directly. Foreign or unavailable land cannot be claimed through this menu.

This is a **server-only update**. Client compatibility remains **3.0.6** and Windows **installer 26** stays current; players do not need to reinstall. This deployment does not replace the already published GitHub 3.0.7 downloads.

The action delegates to the player's native claim command with its normal limits and protection checks. It revalidates authentication, personal claiming mode and the original dimension/chunk, and checks ownership before opening permissions. Offline regression tests and an independent authorization check passed without launching Minecraft.

See [deployment verification](3.0.8-claim-entry.json) for the exact Core hash, backup and restart evidence. Live rendered menu interaction is not part of the offline proof.
