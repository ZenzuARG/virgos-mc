# Virgos-MC 3.0.4

Estado: candidato preparado; la publicación queda pendiente de validación final y autorización remota.

## Menú y autenticación

- `/virgos menu` y `/virgos guia` ahora informan si AuthMe, el paquete cliente o `/login` bloquean la apertura.
- El handshake del paquete 3.0.4 se mantiene alineado entre Códice, servidor y `client-update.json`.

## Create y magia

- Incluye Create: Netherless y Create: Diesel Generators.
- Incluye Enhanced Mastery con la receta de `arcane_essence` corregida para `irons_spellbooks`.
- Mantiene la pasada conservadora de balance de Iron's Spells.
