# Virgos-MC 3.0.7 — server-only KubeJS startup fix

Server release **3.0.7** keeps client release **3.0.6**, installer **25**. No client update is needed.

## Fix
Generated-resource reads now capture bytes and invalidate their lazy cache under the same per-resource monitor. This prevents the reproduced null-cache race without disabling datapacks, replacing bad resources with empty data, or retaining forgotten data. Recipe-stream settings remain unchanged.
